# actual-size-print

画像を指定した実寸サイズでA判・B判の用紙へ配置し、PDFを生成するクライアントサイドWebツールです。

## 使い方

1. `index.html` をブラウザで開く。
2. PNG / JPG / WebPをクリックまたはドラッグ&ドロップで追加する。
3. 用紙サイズと向きを選ぶ。
4. 画像を選択し、幅・高さ・X座標・Y座標をmmで編集する。縦横比固定が初期状態で有効。
5. プレビュー上で画像をドラッグして配置する。用紙外にはみ出すと警告が表示される。
6. 「PDFを生成してダウンロード」を押す。

複数画像（同一ページ上）、複製、同一画像のコピー追加、自動整列にも対応しています。PDF印刷時はプリンター側で「実際のサイズ」または倍率100%を選択してください。

プリンター実寸補正では、指定サイズと実測サイズから `指定サイズ ÷ 実測サイズ` を計算します。例えば100mm指定で実測95mmなら補正倍率は約1.052632倍です。有効時は全画像のPDF出力寸法へ倍率を掛け、補正値はlocalStorageへ保存します。指定値・実測値が未入力、0以下、または数値でない場合はPDF出力を止めてエラーを表示します。

## ホーム画面と機能追加

`index.html` のホーム画面から「生活機能」または「効率化機能」を選ぶと、それぞれのカテゴリ専用ページへ切り替わります。英語筆記体変換は両方のカテゴリから開けます。カテゴリページと各機能ページでは、ヘッダーの「ホームに戻る」でカテゴリ選択画面へ戻れます。設定は右上の歯車アイコンから開けます。デスクトップでは4カードごとに改行し、タブレットは2列、スマートフォンは1列です。機能を追加する場合は、カテゴリのカード、専用ビュー、`showView()` の切り替えを1組として追加します。

「次の連休カウントダウン」は、日本の土日・祝日・振替休日から3日以上連続する休日を抽出し、次の連休までの日数と期間を表示します。2026年から2030年までの祝日データを内蔵し、2028年以降の春分の日・秋分の日は国立天文台の予測日を使用します。正式な祝日の日付は前年2月の官報掲載後に確定します。

「明日の起床時間」は、6:00〜9:00（初期値）の範囲から5分刻みでランダムに起床時間を決めます。範囲は変更でき、決定結果は翌日分として`localStorage`へ保存されます。日付が変わると新しい時間を決め直せます。

「MD5ハッシュ生成」は、文字列または任意形式のファイルから32文字のMD5ハッシュ値を生成し、クリップボードへコピーできます。処理は`md5-generator.js`でブラウザ内だけで行われ、入力データは外部へ送信されません。MD5は改ざん耐性が弱いため、パスワード保存などのセキュリティ用途には使用しないでください。

「メモ帳」は、タイトルと本文をブラウザの`localStorage`へ自動保存し、文字数・行数を表示します。本文のコピー、TXTファイル保存、確認付きの全消去に対応し、サイト全体のJSONバックアップにも含まれます。処理は`notepad.js`へ分離しています。

設定画面の「全データ保存」は、サイト内の現在データを`yaa-site-backup-YYYY-MM-DD.json`へまとめます。実寸印刷の画像・mm配置・補正、文字数カウントと筆記体の入力、形式変換の変換元、トリミング画像と選択範囲、カラー抽出画像・選択色・履歴、画像合成の素材・レイヤー・最大30件の操作履歴、ネオン文字の全設定、表示言語が対象です。「全データ読込」で同じ状態へ復元できます。バックアップはブラウザ内で作成・読込され、外部へ送信されません。読込上限は250MBです。

設定画面では表示言語を日本語・英語から選択できます。選択は全機能のラベル、説明、操作結果メッセージへ反映され、`localStorage`に保存されます。次回起動時とサイト全体バックアップの復元時にも維持されます。翻訳処理は`i18n.js`へ分離しています。

設定画面の「全データ保存」「全データ読込」から、サイト内の画像、配置、文章、履歴、ネオン設定、表示言語をJSONファイルでまとめて保存・復元できます。ファイルは外部サーバーへ送信されません。

文字数カウントは、文字数（空白含む・除く）、行数、UTF-8バイト数を入力中に更新します。文字数はUnicodeコードポイント単位で数えます。

英語筆記体変換は、Unicodeの Mathematical Script の大文字・小文字を使用します。対応するUnicode文字がない英字は、Unicode仕様にある例外コードポイントを使用して補完しています。空白・数字・記号・日本語はそのまま出力されます。

ファイル形式変換は、画像をPNG / JPG / WebPへ、テキストをTXT / HTML / JSONへ変換します。画像はCanvas、テキストはFile APIとBlobを使い、すべてブラウザ内で処理します。JSON出力は入力全文を`text`プロパティに格納します。

画像トリミングは、PNG / JPG / WebPを読み込み、ドラッグまたは元画像ピクセルの数値入力で範囲を指定します。自由比率、1:1、4:3、3:2、16:9、3:4を選択でき、PNG / JPG / WebPで保存できます。処理は`image-cropper.js`へ分離しています。

画像カラー抽出は、PNG / JPG / WebP上のピクセルをクリックまたはドラッグして色を取得します。画像上にポインタがある間だけピクセル拡大鏡を表示します。HEX、RGB、アルファ値、元画像上の座標を表示し、HEXコードをクリップボードへコピーできます。最近選択した色は最大8色まで保持し、履歴消去にも対応します。処理は`image-color-picker.js`へ分離しています。

画像合成・編集は、複数のPNG / JPG / WebPをレイヤーとして追加し、ドラッグ移動、ハンドルでのサイズ変更、数値指定、回転、透明度、重なり順、複製、削除、中央配置、元に戻す・やり直しに対応します。キャンバスサイズと背景を指定し、PNG / JPG / WebPで保存できます。処理は`image-composer.js`へ分離しています。

ネオン文字生成は、複数行テキスト、書体、太字・斜体、文字間隔、行間、文字揃え、横書き・縦書き、2色グラデーション、発光量、ネオン管の太さを調整できます。レンガ壁・暗い壁・単色・透明背景、ネオン看板枠、6種類の配色プリセット、8種類の背景色プリセット、点滅プレビューに対応し、PNG / WebP / SVG / 3秒WebM / 3秒GIFで保存できます。Webページ用CSSもコピーできます。編集設定はlocalStorageへ自動保存され、次回起動時に復元されます。また、ネオンだけを`neon-text-project.json`として保存・再読込することもできます。読み込み時はアプリ識別子、バージョン、値の範囲を検証します。処理は`neon-text-generator.js`へ分離しています。GIFは負荷を抑えるため最大辺720pxかつ約25万画素へ縮小し、透明背景は背景色で塗りつぶします。

## 実寸とプライバシー

- 配置データの正はmm値です。プレビューのpx値は表示とドラッグ量の変換にだけ使います。
- PDFはjsPDFのmm単位ドキュメントを作り、画像の位置・サイズへmm値を直接渡します。内部値は丸めず、表示だけ最大2桁に丸めます。
- 画像はFile APIとCanvasでブラウザ内処理され、外部サーバーへ送信されません。
- jsPDFはCDNから読み込むため、PDF生成時にはインターネット接続が必要です。画像データ自体は送信されません。

## 現在の制約

- ブラウザの印刷ダイアログやプリンターの余白・自動縮小設定は制御できません。PDFを開いてから倍率100%で印刷してください。
- 画像を用紙外へ置いてもPDF生成は可能です。赤い警告を確認してから出力してください。
- WebM生成はCanvas録画に対応するブラウザが必要です。SVG内の文字表示は閲覧環境にあるフォントへ依存します。
- ZIPに含まれていた元ファイルは実質空だったため、今回の4ファイルは仕様に沿うMVPとして実装しています。
