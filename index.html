ACTUAL SIZE PRINT

画像を指定した実寸サイズで印刷

幅・高さ・位置をmmで指定し、A判・B判の用紙へ配置したPDFを作成します。

1. 画像を追加

画像を追加すると、ここに一覧が表示されます。

2. 用紙

プリンター実寸補正

テスト印刷の「指定した長さ」と「実際に測った長さ」から、印刷時の補正倍率を計算します。

補正倍率：1.000000倍（補正なし）

例：指定100mm、実測95mm → 100 ÷ 95 = 1.052631…倍

印刷時はブラウザ・プリンター側の倍率を100% / 「実際のサイズ」にしてください。「用紙に合わせる」等の自動縮小はOFFを推奨します。

3. 選択画像の設定

画像を追加して選択してください。

4. 整列と出力

PDFの画像サイズと位置は、プレビューのpx値ではなくmm値から計算されます。

プレビュー

A4・縦 — 210 × 297 mm

表示は縮尺です

画像をドラッグして自由に配置できます。座標入力で0.01mm単位の位置指定も可能です。

CHARACTER COUNT

文字数カウント

文章を入力すると、各項目をリアルタイムで集計します。

文字数（空白含む）0
文字数（空白除く）0
行数0
UTF-8バイト数0

ENGLISH CURSIVE

英語筆記体変換

英語の大文字・小文字をUnicodeの Mathematical Script 文字へ変換します。

→

英字以外の文字は変更されません。表示には筆記体対応フォントが必要です。

FILE CONVERTER

ファイル形式変換

ファイルを選び、変換先の形式を指定してダウンロードします。

ファイル未選択

対応形式：画像（PNG / JPG / WebP / SVG）、テキスト（TXT / CSV / JSON / MD / HTML）

画像はCanvasで変換します。テキストはTXT・HTML・JSONへ変換できます。

IMAGE CROPPER

画像トリミング

画像上をドラッグして切り抜く範囲を選択し、別ファイルとして保存します。

画像を追加すると編集画面が表示されます。

画像上をドラッグして範囲を選択できます。数値入力は元画像のピクセル単位です。

IMAGE COLOR PICKER

画像から色を抽出

画像上の調べたい部分をクリックして、ピクセルの色とHEXカラーコードを取得します。

画像をクリックして色を選択してください。

最近選んだ色

画像を追加すると、色を選択できる画面が表示されます。

クリックまたは指で触れた位置の色を取得します。ドラッグしながら色を探すこともできます。

IMAGE COMPOSER

画像合成・レイヤー編集

複数画像を重ね、位置・大きさ・回転・透明度・重なり順を編集して保存します。

キャンバス

レイヤー

画像を追加して選択してください。

書き出し

複数画像を追加すると編集を開始できます。

画像をドラッグして移動できます。右下の四角をドラッグするとサイズ変更できます。Deleteキーで選択画像を削除できます。
